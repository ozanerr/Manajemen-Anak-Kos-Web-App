# Manajemen Anak Kos Web App 🏠✍️

Aplikasi manajemen dan kolaborasi berbasis web yang dirancang khusus untuk kebutuhan anak kos. Platform ini membantu penghuni kos mengelola keuangan pribadi, berdiskusi secara langsung (*real-time*), serta memantau tenggat waktu tugas harian agar hidup mandiri menjadi lebih teratur dan produktif.

🌐 **Live Demo:** [aturin-ten.vercel.app](https://aturin-ten.vercel.app)

## 📌 Fitur Utama

- **Otentikasi & Keamanan Pengguna**: Sistem pendaftaran dan login akun yang terintegrasi dengan **Firebase Authentication**.
- **Manajemen Keuangan**: Pencatatan arus kas (pemasukan dan pengeluaran) harian untuk membantu anak kos mengontrol anggaran bulanan.
- **Diskusi Real-time**: Ruang obrolan / diskusi interaktif antar sesama anak kos menggunakan teknologi **Socket.io**.
- **Pelacak Deadline Tugas**: Catatan dan pengingat tenggat waktu (*deadline*) tugas akademik maupun kegiatan harian agar tidak ada yang terlewat.
- **Database Cloud Terpusat**: Penyimpanan data yang aman dan terstruktur menggunakan **MongoDB Atlas**.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Backend**: Node.js, Express.js
- **Real-time Engine**: Socket.io
- **Authentication**: Firebase Authentication
- **Database**: MongoDB Atlas
- **Deployment**: Vercel
